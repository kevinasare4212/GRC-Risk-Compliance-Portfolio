# Sample Risk Assessment Report (RAR)

## Overview
This project contains a sample Risk Assessment Report (RAR) created to demonstrate foundational Governance, Risk, and Compliance (GRC) documentation skills.

- Assess impact and likelihood.
- Calculate a risk score.
- Recommend appropriate mitigation strategies.
